## 🌟 Overview

**CleanCity** is an urban sanitation and waste monitoring application built with Django. It bridges the gap between citizens reporting public garbage overflow and municipal sanitation teams resolving community waste issues.

## ✨ Key Features

1. **Modern Green & White UI:** Clean, responsive design optimized for mobile, tablet, and desktop.
2. **Citizen Waste Reporting:** File complaints with category selection (Plastic, Organic, E-Waste, Paper, Hazardous, etc.), location, landmark, urgency level, and optional site photos.
3. **Automated Tracking IDs:** Unique ticket assignment (e.g., `WM-0001`).
4. **Status Workflow:** Real-time updates:
   - 🟡 **Pending Review**
   - 🔵 **In Progress / Dispatched**
   - 🟢 **Collected & Cleaned**
   - 🔴 **Rejected / Invalid**
5. **Interactive Dashboard:** Live summary counters (Total, Pending, In Progress, Collected) and recent tickets.
6. **Dedicated Admin Portal:** Staff administration panel to inspect, filter, update urgency, and resolve reports.
